# Introduction
This project is centered around the building of a Markov Chain algorithm in Python to simulate the writing of Shakespearean sonnets. This program will read in a .txt file with Shakespeare's sonnets and create a dictionary of states and probabilities of each states emissions. The final output will be a randomly generated sentence using the Markov model created.

output: Randomly generated text using the sonnets as a model

```
FUNCTION build_markov_model(markov_model, curr_sonnet, order):

    ADD an ending state

    FOR each position in current_sonnet:
        CREATE the current state based on order
        IDENTIFY the word that follows the current state

        IF the current state is not in markov_model:
            ADD the current state to markov_model

        IF the next word is not stored for the current state:
            ADD the next word with a frequency of 0

        ADD 1 to the next word’s frequency in dictionary

    RETURN markov_model
```
